# AI 商店私聊的币种追问

Status: done

## Problem Statement

玩家问完一件装备后追问「银币多少」。资料预取只使用追问原文，可能把银币道具误当成新查询对象。

## Solution

私聊保留上一轮从游戏目录明确查到的物品 ID。对只询问币种和价格的短句，用原物品重新查价。缺乏可靠指代时请玩家补充物品。

## User Stories

- 别名命中某根钓竿后，玩家可以追问它的银币参考价。如果只记录金币价，助手如实说明。
- 询问另一个型号或切换话题后，追问只使用最近一轮的可靠物品。不同玩家、角色或代次互相隔离。

## Implementation Decisions

- 保存物品 ID 的内存元数据随私聊缓存淘汰和清空，绑定角色授权修订、角色代次与急停代次。指代有时限，只从当前玩家原话的唯一目录命中产生。
- 简短币种追问通过原只读商店工具重查价格并以固定话术回复。新主题、频道聊天与普通闲聊继续走正常对话。
- 同一批次的私聊按会话顺序处理，其他会话可并行。价格和币种由现有静态价目提供。

## Testing Decisions

- 用测试静态库和模拟模型复现原问答。验证银币无报价、银币有报价、多义简称、换话题、时效和会话隔离。
- 验证追问无需模型猜测，查一次实际目录且继续经过角色授权和急停检查。

## Out of Scope

本次处理商店私聊的短币种追问。游戏内门店实时价格和公网共享频道指代另行处理。
