# AI 角色活动范围的成员回显与重新添加

Status: done

## Problem Statement

添加 AI 角色后，活动范围仍可能显示未订阅。恢复已删除的角色后，重新添加原频道可能收到成功回执，角色却仍未加入。新存档的频道列表也可能为空。

## Solution

活动范围按角色内部标识回显。游戏服确认后刷新精确频道，已有禁用记录时重新启用。尚无频道记录时，管理员可输入已知的频道标识。

## User Stories

1. 管理员添加、移除地图或频道后，可以看到该角色实际订阅的范围，即使角色改名或与其他角色同名。
2. 恢复角色后可以重新添加原频道。页面显示命令处理状态以及拒绝原因，读取失败时可以重试。

## Implementation Decisions

- `GET /api/ai/channels` 为地图和频道列表各项增加 `agent_keys`，保留 `agents` 显示名、计数，以及含地图和全局范围的 `subscribed`。
- 精确频道继续由游戏服事务执行。启用已有禁用记录时保留优先级和冷却设置。
- 无数据库迁移、管理鉴权变更或游戏客户端协议变更。回滚代码即可恢复旧接口，数据仍可由旧版读取。

## Testing Decisions

- 用迁移后的 SQLite 和实际游戏服命令消费者验证同名角色订阅、禁用记录重新启用及移除。添加后在频道与地图各项断言固定的角色标识及显示名。
- 覆盖管理页活动范围操作和命令未生效时的提示。

## Out of Scope

角色活动范围覆盖精确频道、地图和全局订阅。本次沿用这三种范围的优先级、能力门禁和游戏服命令队列。
